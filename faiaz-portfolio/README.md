# Zarif Md Faiaz — Portfolio

A responsive portfolio website built with plain HTML, CSS and JavaScript.

## Publish for a free, persistent public link (GitHub Pages)
1. Sign in to GitHub and create a new **public** repository, for example `faiaz-portfolio`.
2. Upload every file and folder from this project ZIP (including `assets`) to the repository root.
3. In the repository, go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**; select `main` and `/ (root)`, then Save.
5. GitHub will publish a URL like `https://YOUR-USERNAME.github.io/faiaz-portfolio/`. This link can be added to your CV and LinkedIn.

The site is static, so no backend or hosting fee is required. GitHub Pages links are persistent while the repository/account and service remain available; it cannot be guaranteed forever.

## Files
- `index.html`: content and layout
- `style.css`: styling and responsive design
- `script.js`: mobile menu and dynamic year
- `assets/`: portrait and certificate images
